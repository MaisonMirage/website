Synthèse Executive

Le laboratoire Maison Mirage évolue d'une unité mono-produit (trompe-l'œil) vers un centre de production multi-produits servant une chaîne de 3 à 10 points de vente. Cette expansion nécessite une refonte majeure des capacités de production, de la chaîne du froid et de la logistique interne.

Dix changements critiques

  1. Batteur 20L → 60L : Pour crêpes + pancakes à 5+ boutiques = 50-75L/jour. Sinon, 3-4 fournées/produit = 2h temps machine/jour perdu.
  2. Ajout laminoir : 15kg pâte sucrée = 45min à la main vs 10min au laminoir. Sur 200 tartelettes/jour = 1h30 de gain.
  3. 2ème armoire positive : Tiramisu (DLC 48h), pâtes crêpes (DLC 24-48h) ne partagent pas l'espace matières premières sans contamination croisée.
  4. 4ème congélateur : Tartelette shells (−18°C long terme) + backup stock + trompe-l'œil nécessitent ségrégation.
  5. Zone portionnement/étiquetage : Chaque boutique reçoit ses propres portions. Sans zone dédiée, risque de confusion et délai expédition.
  6. Climatisation obligatoire : Trompe-l'œil + Cup Dubai = travail chocolat à 18-20°C. Hors AC, la cuisine monte à 25-28°C l'été.
  7. Bain-marie flan : Nécessite zone séparée (four + bacs GN) de la pâtisserie sèche pour hygiène.
  8. Doseur à piston : Vitesse de portionnement : 1 bac crêpes par boutique en 30sec vs 5min à la louche. Pour 5 boutiques = gain 3min/jour ou crise avant le départ.
  9. Étiquetage DLC/DLUO batch : Multi-boutique = traçabilité obligatoire. Chaque lot = identifiant + date.
  10. Plan d'allergen : Gluten, œufs, lait, fruits secs. Procédures croisées nécessaires.

Analyse critique du Plan V3

Ce qui a fonctionné dans V3

✓ Flux circulaire

Stock → Prép → Îlot → Montage → Congélo → Finition → Expédition. Aucune rétro-progression, pas de croisement.

✓ Congélateurs stratégiquement placés

Entre montage et finition. Accès direct depuis zone aérographie. Score de flux excellent.

✓ Stock froid proche prép

Armoire positive à 5m de l'îlot. Aucune perte de temps. Zoning parfait pour mono-produit.

✓ HACCP basics

Sas d'entrée, stocks séparés (sec/froid), sol époxy. Fondamentaux en place.

✓ Îlot central 2.50m × 1.20m

Inox, robuste, ergonomie validée. À conserver identiquement.

✓ Zones spécialisées claires

Montage trompe-l'œil, aérographie, congélation. Chacune isolée = moins de contamination.

Limitations majeures pour la portée V4

1. Batteur 20L — Goulet d'étranglement critique

Problème : Le batteur 20L est inadéquat pour production multi-boutique de crêpes et pancakes.

Volume journalier attendu :

  • Crêpe batter : ~15L par boutique, 5 boutiques = 75L/jour
  • Pancake batter : ~10L par boutique, 5 boutiques = 50L/jour
  • Total pâtes : 125L/jour (hors trompe-l'œil, tartelettes)

Avec 20L : 6-7 fournées par jour = 4-5 heures de temps machine. Invendable.

Avec 60L : 2-3 fournées = 1-1.5 heures. Acceptable.

Solution : Remplacer par Hobart HL600 ou Bear Varimixer AR60 (60L), modèle planétaire avec bol basculant.

2. Absence totale de laminoir — Tartelettes impossibles en volume

Problème : V3 n'a pas de laminoir pour tartelettes (pâte sucrée/sablée).

Volume estimé : 200-300 tartelettes/jour à 3-4 boutiques.

Abaisser 15kg pâte :

  • À la main : 45-50 minutes
  • Au laminoir : 10-12 minutes
  • Gain : 35-40 min/jour

Solution : Laminoir de table (Rondo Sigma 700mm ou Fritsch P2025). Budget : €3,500-5,000.

3. Pas de zone bain-marie — Flan inviable

Problème : Flan production requiert cuisson en bain-marie (temps 35-45min à 160°C). V3 n'a pas de zone dédiée.

Besoins :

  • Bacs gastronormes 2/1 (pour bain-marie dans four)
  • Espace aérié (extraction vapeur)
  • Table de refroidissement avant congélation

Solution : Zone flan dédiée près du four à sole, avec extraction dédiée.

4. Zone conditionnement/expédition sous-dimensionnée

Problème : V3 a 3m² pour emballage trompe-l'œil. Multi-boutique = beaucoup plus.

V4 doit gérer :

  • Portionnement batter crêpes/pancakes dans containers par boutique
  • Étiquetage DLC/DLUO per batch
  • Staging par commande (Boutique A : 50 crêpes, 30 tartelettes, 10 flans, etc.)
  • Stockage temporaire avant dispatch

Solution : Agrandir à 6m², ajouter table étiquetage + station portionnement.

5. Armoire positive 700L insuffisante

Problème : 1 armoire ne peut pas contenir :

  • Tiramisu finalisé (DLC 48h, ~20L)
  • Pâtes crêpes/pancakes portionnées (DLC 24-48h, ~30L)
  • Matières premières (beurre, crème, œufs) = contamination croisée

Stockage V4 requis : Minimum 1,400L (2 × 700L armoires).

Solution : Ajouter 2ème armoire positive +2/+4°C, placer stock premières dans Armoire 1, produits finalisés/semi-finis dans Armoire 2.

6. Trois congélateurs insuffisants

Stocks −18°C :

  • Trompe-l'œil finies (stockage 4-6 semaines)
  • Tartelette shells (long terme)
  • Tiramisu bulk (avant portionnement)
  • Cup Dubai components

V3 avec 3 congélateurs : Espace serré, pas de buffer.

Solution : Ajouter 4ème congélateur −18°C. Idéalement, plan Phase 2 = chambre froide.

7. Pas de climatisation

Problème : Trompe-l'œil et Cup Dubai = travail chocolat.

  • Température requise : 18-20°C
  • Cuisine actuelle : 22-24°C à repos, 26-28°C l'été
  • Tempérage échoue, trempage chocolat vire blanc (blooming)

Solution : AC obligatoire, 2-3 tons. Budget : €4,000-6,000 installation.

Flux détaillé par produit

Trompe-l'œil (cookies + fruits réalistes)

  • Fabrication : Pâte → cuisson → tempérage chocolat → aérographie détail → congélation
  • Équipement : Four à sole, tempéreuse, aérographe
  • Stockage : Congélateur (−18°C), 30 jours
  • Transport : Boîtes isothermes, pas d'exposition chaleur

Tiramisu

  • Fabrication : Mascarpone + zabaglione + biscuits imbibés → jars individuels
  • Équipement : Batteur (crème), jars verre (50-100mL), armoire positive
  • Stockage : +2/+4°C, 48h max
  • Transport : Isotherme avec ice packs. DLC affichée sur chaque jar.
  • Note : Cru (mascarpone pasteurisé + œufs pasteurisés) = hygiène critique.

Flan

  • Fabrication : Crème anglaise versée en ramequins → bain-marie à 160°C, 35-45min → refroidissement → rangement
  • Équipement : Batteur (crème), bacs GN 2/1, four, ramequins, table refroidissement
  • Stockage : +2/+4°C, 72h DLC
  • Transport : Boîtes isothermes, pas d'empilement (fragile)

Crêpes

  • Fabrication (Lab) : Farine + œufs + lait → batteur 60L → repos 30min → portionnement 2-3L per container par boutique
  • Finition (Boutique) : Décongelation lente (12h froid) → cuisson crêpière
  • Équipement Lab : Batteur 60L, doseur à piston, containers hermétiques 2-3L
  • Stockage : +2/+4°C, 48h DLC
  • Transport : Isotherme. NE PAS cooked, risk de dessèchement + coût transport vs batter.
  • Volume : ~15L par boutique. 5 boutiques = 75L/jour, soit 1 fournée 60L + 1 de 15L.

Pancakes

  • Fabrication (Lab) : Farine + levure chimique + œufs + lait → batteur → portionnement 1-2L containers
  • Finition (Boutique) : Décongelation lente → cuisson griddle ou plaque
  • Équipement Lab : Batteur 60L, doseur
  • Stockage : +2/+4°C, 48h DLC
  • Volume : ~10L par boutique. 5 boutiques = 50L/jour.

Tartelettes

  • Fabrication (Lab) : Pâte sucrée/sablée → laminoir → découpe moule → cuisson optionnelle (ou cru-congelé) → refroidissement → garnitures (crème pâtissière, ganache, fruit)
  • Équipement Lab : Batteur, laminoir, four, moules tartelette, garnissage (spatule/tuyau)
  • Stockage : Shells −18°C (60j), garnitures +2/+4°C (5j)
  • Finition optionnelle (Boutique) : Montage shell + garniture + décor = fraîcheur maximale
  • Transport : Shells congelées, garnitures isolées. Monotherme possible.
  • Volume : 200-250 tartelettes/jour = 8-10 fournées laminoir (20-25 tartelettes/fournée).

Cup Dubai

  • Fabrication (Lab) : Kataifi croustillant (four) + pistache cream (batteur) + chocolat tempéré + aérographie décor → congélation assemblée OU stockage composants séparés
  • Équipement Lab : Four, tempéreuse, moule, batteur, aérographe
  • Stockage : −18°C, 30 jours
  • Finition optionnelle (Boutique) : Trempage chocolat + décor supplémentaire
  • Volume : 20-30 pcs/jour (produit premium, marge élevée).

Justifications du layout V4

Pourquoi scinder "Prép Pâtes" et "Prép Cuisson" ?

Différentes sources de contamination :

  • Prép Pâtes : Batteur (projections), laminoir (poussière farine) → nécessite extraction localisée
  • Prép Cuisson : Vapeur four, fumée induction → extraction différente, zone plus chaude
  • Séparation : Évite contamination croisée, facilite nettoyage indépendant

Congélateurs entre montage et expédition

Placement stratégique :

  • Accès immédiat après aérographie (trompe-l'œil fraîche → congélo rapid)
  • Puis accès direct à expédition (dégel vers dispatch)
  • Évite retour arrière, flux linéaire

2ème armoire positive dans Stock Froid

Séparation matières premières vs produits finalisés :

  • Armoire 1 : Beurre, crème, œufs, matières premières brutes
  • Armoire 2 : Tiramisu finalisé, pâtes crêpes portionnées, flan DLC < 72h
  • Réduit contamination croisée, facilite contrôle DLC

Zone Conditionnement/Expédition agrandi (6m²)

Multi-boutique = logistique complexe :

  • Portionnement : Crêpes/pancakes en containers par boutique (30sec/container au doseur)
  • Étiquetage : DLC/DLUO batch + code barre boutique (thermique rapide)
  • Staging : Montagne de boîtes, chacune laborée "Boutique A", "Boutique B", etc.
  • Attente dispatch : Isotherme temporaire si expédition décalée

Calcul puissance AC requise

Formule simpifiée : Puissance AC (kW) ≈ Apport calorique (kW) × 1.2-1.5 (facteur sécurité)

7-8 kW × 1.3 = 9-10 kW (≈ 2.5-3 tons frigorifiques)

Spécifications climatisation V4

Température cible

  • Zone montage/trempage chocolat : 18-20°C strictement (tempérage chocolat requires ≤ 28°C avant et pendant).
  • Reste du lab : 22°C acceptable (batter, crème préparation).
  • Solution : Clim centralisée 20°C lab entier (plus sûr, simple).

Hygrométrie

  • Cible : 50-60% humidité relative.
  • Trop sec (<40%) : Pâtes dessèchent, crêpes cassantes.
  • Trop humide (>70%) : Condensation parois frigo, blooming chocolat.
  • Clim moderne = déshumification automatique.

Type & installation

  • Split inverter : Unité extérieure + intérieure. Silencieuse, économe, fiable.
  • Modèles recommandés : Daikin Perfera FTXM25R / Fujitsu Nocria ASYG09KGTB (2.5 kW each).

1. Batteur planétaire 60L — COMMANDE URGENTE

CRITIQUE

CRITIQUE

Justification : Trompe-l'œil + Cup Dubai exigent 18-20°C. Hors AC, T° atteignent 28°C été = blooming chocolat = perte €1,200/semaine.

Action : Appel 3 installateurs AC pro (Daikin, Fujitsu). Devis install 4-6 semaines.

Timeline : Commande mars → install mai (avant été).

3. Laminoir 700mm — URGENT

CRITIQUE

Timeline : Commande mars → livraison avril.

CRITIQUE

Justification : 1 armoire + 3 congélos insuffisant pour tiramisu/flan/batters DLC + séparation matières premières. Risque contamination croisée + gestion DLC chaos.

IMPORTANT

IMPORTANT

IMPORTANT

IMPORTANT

RECOMMANDÉ
