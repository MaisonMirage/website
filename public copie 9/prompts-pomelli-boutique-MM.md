## NOTES TECHNIQUES POMELLI

### Principe directeur : CRÈME DOMINE
Le site web de Maison Mirage est crème (#FAF5EF) en dominante, avec du noir uniquement pour le texte et des touches d'or. La boutique DOIT refléter cette identité. Si le render sort trop sombre, trop noir, trop cave → refaire. L'intérieur doit évoquer le site web en 3D : chaud, crème, lumineux, or.

### Paramètres recommandés
- **Style** : Architectural Photography / Interior Design Editorial
- **Éclairage** : Natural daylight + warm LED spots (3000K)
- **Aspect ratio** : 16:9 (façade/intérieur) ou 4:5 (Instagram) ou 9:16 (Stories/Reels)
- **Qualité** : Maximum / HD

### Ordre de priorité
1. **V1** (vitrine jour, hero shot) → valider le concept vitrine crème
2. **I1** (intérieur général) → valider le layout crème-et-or
3. **F1** (façade jour) → la version corrigée fidèle au site
4. **V2** (vitrine soir) → le mood nocturne chaleureux
5. **I3** (jewelry cabinet close-up) → réseaux sociaux
6. **I6** (mode After Dark) → valider le concept soirée
7. Le reste selon les besoins

### Erreurs à éviter
- **TROP NOIR** : Le piège n°1. Les murs NE SONT PAS noirs. Ils sont CRÈME #FAF5EF. Le noir est UNIQUEMENT pour les cadres fins, le texte, et l'awning. Si Pomelli génère un intérieur sombre → préciser "CREAM WALLS, NOT BLACK, warm and luminous, #FAF5EF everywhere"
